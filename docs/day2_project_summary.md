# Project Summary

This project is a job portal security system that monitors user behavior, login activity, resume uploads, and API requests. It detects suspicious actions such as SQL Injection, XSS, bot activity, brute-force login attempts, and unauthorized access. The system then sends alerts and response suggestions to protect candidate data.

## Problem Statement
Recruitment platforms store sensitive candidate information such as resumes, contact details, education history, and work experience. Attackers can use bots, SQL injection, XSS, and other methods to steal this data. Existing security systems often detect attacks too late. This project aims to predict threats early and respond automatically.

## Objectives
- Collect and monitor user activity logs.
- Detect suspicious behavior using rules and machine learning.
- Classify threats into meaningful categories.
- Generate alerts and response recommendations.
- Protect resume data from unauthorized access.

## Pages in the website
