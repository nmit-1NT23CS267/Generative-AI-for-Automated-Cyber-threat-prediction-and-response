\# Day 9 Dashboard Design



\## Dashboard Sections



\### 1. Overview Metrics

\- Total alerts

\- Alerts by severity (Critical, High, Medium, Low)

\- Total activity logs

\- Unique attacking IPs



\### 2. Recent Alerts Table

\- Alert ID

\- Category

\- Severity

\- Timestamp

\- Risk score



\### 3. Activity Logs

\- Recent login events

\- Resume upload events

\- Suspicious activity



\### 4. Threat Explanations

\- Human-readable threat summaries

\- Immediate actions

\- Long-term mitigation



\### 5. Security Trends

\- Alerts over time

\- Most common threat categories

\- Top attacking IPs



\## Color Coding

\- Critical: Red

\- High: Orange

\- Medium: Yellow

\- Low: Green
