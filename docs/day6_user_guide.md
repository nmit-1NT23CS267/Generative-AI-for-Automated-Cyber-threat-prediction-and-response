\# Day 6 User Guide



\## Starting the System



1\. Start the FastAPI backend.

2\. Start the frontend using a local web server.

3\. Open the frontend in a browser.



\## Candidate Login



1\. Enter an email address.

2\. Enter the password.

3\. Click Login.

4\. Read the status message.



For the current academic prototype, the demo password is:



123456



\## Resume Upload



1\. Enter the candidate email.

2\. Select a PDF, DOC, or DOCX resume.

3\. Click Upload Resume.

4\. Read the upload result.



\## Security Monitoring



\### View Activity Logs

Click View Activity Logs to see login and resume-upload events.



\### Analyze Logs

Click Analyze Logs to run the detection engine on the activity log.



\### View Alerts

Click View Alerts to display generated security alerts.



\## Important Limitation



This is a local academic prototype. It does not yet provide real authentication, production database storage, email alerts, or permanent IP blocking.
