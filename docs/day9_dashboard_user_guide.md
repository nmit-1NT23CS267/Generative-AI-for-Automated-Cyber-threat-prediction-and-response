\# Day 9 Dashboard User Guide



\## How to Start

1\. Start the FastAPI backend.

2\. Start the Streamlit dashboard.

3\. Open the dashboard URL in a browser.



\## Dashboard Sections



\### Overview

Shows total alerts, severity breakdown, and key metrics.



\### Recent Alerts

Displays the latest 20 alerts with category, severity, and timestamp.



\### Activity Logs

Shows recent login and resume upload events.



\### Threat Explanations

Provides human-readable explanations for each detected threat.



\## Refresh

The dashboard auto-refreshes every 10 seconds to show new alerts.
