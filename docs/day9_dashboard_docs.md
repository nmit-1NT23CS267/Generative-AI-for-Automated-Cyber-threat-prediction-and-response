\# Day 9 Dashboard Documentation



\## Purpose

The security dashboard provides a visual interface for administrators to monitor threats, view activity logs, and understand security alerts.



\## Features

\- Real-time alert monitoring

\- Severity-based color coding

\- Activity log viewer

\- Threat explanation display

\- Security metrics summary



\## Technology

\- Frontend: Streamlit

\- Backend: FastAPI

\- Database: PostgreSQL



\## Benefits

\- Reduces time to understand threats

\- Provides actionable insights

\- Improves security monitoring efficiency

\- Demonstrates project capabilities during viva
